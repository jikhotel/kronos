# 远程 QMT 通道 — 云服务器部署指南

> 目标: 在**云 Windows 服务器**上运行 QMT 客户端 + 桥接服务, 让 Mac 上的 Kronos
> 实盘引擎通过 HTTP 远程下单。Mac 无需运行任何 Windows 软件。

```
┌───────────── Mac (Kronos 系统) ─────────────┐        ┌───────── 云 Windows 服务器 ─────────┐
│  实盘引擎 LiveEngine                        │        │  qmt_bridge.py  (HTTP, 端口17890)  │
│   └─ RemoteQmtBroker ──(url+token)──────────┼───────▶│   └─ xtquant → miniQMT 客户端      │
│      quant/brokers.py                       │ HTTPS/ │        └─ 券商柜台(国金)           │
└─────────────────────────────────────────────┘  HTTP  └────────────────────────────────────┘
```

## 第一步: 租云 Windows 服务器

| 项目 | 建议配置 |
|---|---|
| 系统 | Windows Server 2019/2022 中文版(或阿里云/腾讯云「Windows 专用云电脑」) |
| 规格 | 2核4G 起步(挂 QMT 客户端 + 桥接足够) |
| 带宽 | 1–3 Mbps 固定带宽即可(A股信号频率低) |
| 计费 | 按量/包月均可; 长期跑选包月 ≈ 几十~百余元/月 |
| 备注 | 云服务器还解决了「Mac 合盖断电策略停跑」的问题, 云端 7×24 在线 |

可选: 阿里云 ECS / 腾讯云 CVM / 华为云, 任选一家, 选就近地域(上海/深圳)。

## 第二步: 云端安装(约 20 分钟)

1. **装 Python 3** — https://www.python.org/downloads/ 勾选 "Add to PATH"
2. **装 QMT 客户端** — 用国金客户经理提供的专属安装包(自助渠道下载的登不了柜台),
   登录资金账号 40735103, 启用「独立交易 / miniQMT」模式
3. **下载本目录** — 把 `qmt_bridge.py` 拷到云端任意目录(如 `D:\kronos-bridge\`)
4. **安装 xtquant**:
   ```bat
   pip install xtquant
   ```
5. **启动桥接服务**(先跑通, 后面再做自启):
   ```bat
   python qmt_bridge.py --userdata "D:\国金QMT交易端\userdata_mini" --account 40735103
   ```
   启动后会打印自动生成的 **token**, 抄下来。
6. **放行端口** — 云控制台安全组/防火墙放行 TCP 17890, **来源限制为你的家庭出口 IP**
   (百度搜"我的IP"得到), 不要对 0.0.0.0/0 全开。

## 第三步: Mac 端接入(1 分钟)

1. Kronos WebUI → 量化交易 → 实盘 → 券商账户管理 → 添加账户:
   - 名称: `国金-云端`
   - 券商通道: **远程 QMT 通道 (云端桥接)**
   - 资金账号: `40735103`
   - 交易密码: 留空(密码由云端 QMT 客户端管理, 无需填)
   - 通道配置:
     ```json
     {"url": "http://云服务器公网IP:17890", "token": "抄下来的令牌"}
     ```
2. 点「🔌 测试连接」→ 显示 *远程通道连接成功, 可用资金 xxx* 即达标
3. 引擎通道选该账户 → 勾选风险确认 → 启动引擎, Mac 端每 60 秒轮询信号并远程下单

## 第四步(推荐): 桥接服务开机自启

用 Windows 任务计划程序: 触发器「系统启动时」, 操作
`python D:\kronos-bridge\qmt_bridge.py --userdata ... --account 40735103 --token 固定令牌`。
QMT 客户端也可在开机后设置自动登录(客户端内设置, 注意锁屏安全)。

## 安全清单

- [x] 所有请求带 token(`X-Bridge-Token`), 无 token 返回 401
- [x] 云端不存策略代码, 只转发下单指令; Mac 端密码仍本地加密
- [ ] **必做**: 安全组仅放行你自己的出口 IP
- [ ] 建议 token 固定为长随机串(启动参数 `--token`)
- [ ] 建议先小资金运行 1–2 周观察成交回报
- ⚠️ HTTP 明文传输: 若云厂商支持, 可用其内网/专线或自行套 nginx + TLS
- ⚠️ 程序化实盘记得走券商的程序化报备(客户经理可代办)

## 无云端联调(mock 模式)

没有云服务器时, 任意一台电脑(包括 Mac)可本地验证全链路:

```bash
python bridge/qmt_bridge.py --mock --token test    # 端口 17890, 模拟资金 100 万
```

然后 Mac 端添加账户, 通道选「远程 QMT 通道」, 配置
`{"url": "http://127.0.0.1:17890", "token": "test"}`, 测试连接应显示
*远程通道连接成功(mock…)*。下单/持仓/资金全部走模拟撮合, 验证引擎链路真实可用。
